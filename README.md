## Featured Projects

### [Credit Risk AI](https://gen-ai-2.vercel.app/) &nbsp;·&nbsp; [Source](https://github.com/naveendhaterwal/gen-ai-2) &nbsp;·&nbsp; *Team Project — Apr 2026*

AI-powered credit risk assessment tool built to help lenders make data-driven borrower decisions while staying compliant with RBI lending policy.

- Full-stack app with a frontend form capturing 10+ borrower metrics (income, CIBIL score, loan purpose, etc.) feeding a neural network for creditworthiness scoring.
- Policy-aware scoring logic achieving **99% accuracy** across borrower data, served through a real-time inference API.
